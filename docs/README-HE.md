# Transparent Fit: התקנה בטלפון (5 דקות, בחינם)

זו האפליקציה המלאה עם **מצלמה חיה**. כדי שהטלפון יאשר מצלמה, היא צריכה לרוץ מכתובת מאובטחת (https).
פותחים אותה מהדפדפן, ו"הוסף למסך הבית" הופך אותה לאפליקציה עם אייקון שנפתחת במסך מלא.

## מבנה התיקייה: לא לשנות
הקוד טוען את המודלים והאייקונים מתיקיות משנה. אם מעלים את הקבצים "שטוחים", זיהוי הגוף לא ייטען.

```
TransparentFit-App/
├── index.html
├── manifest.webmanifest
├── sw.js
├── vision_bundle.mjs
├── vision_wasm_internal.js
├── vision_wasm_internal.wasm
├── models/   seg-1.wasm  seg-2.wasm  pose.wasm
└── icons/    icon-192.png  icon-512.png  maskable-512.png  apple-touch-icon.png
```

**לא פותחים את index.html בלחיצה כפולה מהמחשב.** הדפדפן חוסם קבצים מקומיים, ויופיע "Body detection couldn't load". צריך להעלות לכתובת https לפי ההוראות למטה.

## אפשרות 1: Netlify (הכי קל)
1. נכנסים במחשב ל-https://app.netlify.com/drop ונרשמים בחינם (אפשר עם Google).
2. גוררים את **כל התיקייה TransparentFit-App** (אחרי חילוץ מה-ZIP) לתוך האזור באמצע המסך.
3. אחרי כחצי דקה מקבלים כתובת, למשל https://shiny-fit-123.netlify.app.

## אפשרות 2: GitHub Pages
1. יוצרים repository חדש ב-GitHub ומעלים אליו את כל הקבצים, **עם התיקיות models ו-icons**.
2. Settings ← Pages ← Branch: main ← Save.
3. אחרי דקה הכתובת מופיעה באותו מסך.

## בטלפון
1. פותחים את הכתובת ב-Chrome (אנדרואיד) או ב-Safari (אייפון).
2. מאשרים גישה למצלמה כשמתבקש.
3. **אנדרואיד:** תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".
   **אייפון:** כפתור השיתוף ← "הוסף למסך הבית".
4. מעכשיו יש אייקון Transparent Fit, והאפליקציה נפתחת במסך מלא.

## צילום תמונת הגוף (שלב 1)
לוחצים על כפתור הצילום הלבן והמצלמה נפתחת בתוך האפליקציה, עם קו מתאר של גוף לעמוד בתוכו.
- **מראה (ברירת מחדל):** המצלמה הקדמית, מוצגת כמו מראה. מעמידים את הטלפון, מתרחקים עד שכל הגוף בתוך הקו, ויש טיימר של 10 שניות.
- **מצלמה אחורית:** כשמישהו אחר מצלם, או כשמצלמים את ההשתקפות במראה גדולה בתא המדידה. הטיימר כבוי כברירת מחדל.
- את הטיימר מחליפים בכפתורים מעל התמונה: בלי טיימר, 3 שניות, 10 שניות.
- לוחצים שוב על כפתור הצילום כדי לצלם. החץ למעלה משמאל מבטל.

## שלב 3: לכוון לבגד
- מכוונים את **אמצע המסך** אל הבגד, קרוב מספיק כדי שהוא ימלא את רוב התמונה. האפליקציה מזהה את הבגד, ממלאת את צורת החולצה רק בבד שלו ומשאירה בחוץ את המתלה, הקולב והבגדים שלידו.
- אם הבגד רחוק מדי תופיע הודעה "Move closer". מתקרבים צעד.
- **לוק מלא (Full Outfit):** מכוונים לחולצה ולוחצים "Save this shirt". החולצה נשארת עלייך, והמצלמה עוברת לבד למכנסיים. מכוונים למכנסיים ושומרים גם אותם. נגיעה בחולצה או במכנסיים על המסך בוחרת איזה חלק המצלמה ממלאת.
- בגד מהארון אפשר לגרור באצבע כדי להזיז אותו על הגוף, ולצבוט כדי לשנות גודל.

## עדכונים
מעלים גרסה חדשה באותה דרך (גוררים שוב את התיקייה ל-Netlify, או מעלים ל-GitHub).
הטלפון מקבל את הגרסה החדשה **בפתיחה הבאה** של האפליקציה, גם כשהיא מותקנת במסך הבית.
אם מחליפים את קבצי המודלים או המנוע (`models/` או `vision_*`), משנים ב-`sw.js` את `VERSION` למספר חדש, למשל `tf-v3`.

## איך זה חותך את הבגד
אחרי שמעלים תמונה, הטלפון "קורא" אותה כמה שניות (רואים "Reading your clothes… %"). זה קורה פעם אחת לכל תמונה.
- מודל שמפרק את התמונה ל-18 חלקים: חולצה, מכנס, חצאית, שמלה, ידיים, רגליים, פנים, שיער ונעליים.
- תיקון לפי שלד הגוף: הגבול בין החולצה למכנס הוא קו אחד לרוחב הגוף, יד חשופה נשארת יד, ובתמונה עד המותניים אין מכנס או שמלה.
- הקצה של החיתוך נצמד לקווים של התמונה עצמה.
- שרוול קצר או ארוך, ומכנס קצר או ארוך, מתארכים לאורך היד או הרגל שלך. מכנס קצר מכסה גם את המכנס הקצר שלך, ומעל מכנס ארוך הוא נגמר באורך שלו.

תמונה חדה ומוארת = חיתוך מדויק יותר.
המודל (SegFormer-B2) מותר לשימוש פרטי ולבדיקות. לשימוש מסחרי צריך רישיון מ-NVIDIA.

## מדידה בחנות: צילום אוטומטי
מכוונים את הטלפון לבגד התלוי. כשהבגד ממלא את אמצע המסך והיד יציבה לרגע, האפליקציה מצלמת לבד: הבזק קטן, רטט, וכתוב CAPTURED.
- **Next**: חוזרים למצלמה החיה ועוברים לבגד הבא. האפליקציה מחכה עד שתזיזו את הטלפון לבגד אחר.
- **Save to wardrobe**: שומר את הבגד בארון.
- נגיעה בתמונה מצלמת גם ידנית. נגיעה נוספת חוזרת למצב חי.
- אפשר לכבות את הצילום האוטומטי ב-Profile ← Auto capture.

## להחליף גבר/אישה
במסך הבית יש כפתור "Women's · Change" (או "Men's · Change") מתחת לכותרת. אפשר להחליף גם ב-Profile ← Display ← Clothing.

## מה שומרים ואיפה
התמונה שלך, הבגדים והלוקים נשמרים **רק בטלפון שלך**. שום דבר לא עולה לשרת.
זיהוי הגוף והבגדים רץ על הטלפון עצמו, ואחרי הפתיחה הראשונה האפליקציה עובדת גם בלי רשת.
